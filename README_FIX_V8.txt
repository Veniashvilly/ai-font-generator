AI FONT GENERATOR — V8: декоративные шрифты
==========================================
Обновление подготовлено на основе исходников из присланного полного ZIP.

УСТАНОВКА (Windows, PowerShell)
1. Закрыть advanced_gui.py. Сохранить резервную копию заменяемых файлов.
2. Распаковать содержимое ZIP прямо в D:\project_7_sem, разрешить замену.
   Папки engine/ и tests/ должны объединиться с существующими.
3. Из корня проекта выполнить:
   .\font-generator-venv\Scripts\python.exe -m pip install "shapely>=2.1,<3"
   .\font-generator-venv\Scripts\python.exe advanced_gui.py
   Shapely устанавливает NumPy как зависимость. Для Pillow и skia-pathops
   ничего не меняется, если они уже установлены. requirements.txt сохраняет
   исходное ограничение fonttools и добавляет новую зависимость.

ЧТО ИЗМЕНЕНО
- engine/filled_geometry.py: новый алгоритм залитой области с non-zero winding,
  объединением пересечений, поиском замкнутых белых областей и оффсетом.
  Исходные квадратичные кривые в этом режиме аппроксимируются отрезками.
- engine/advanced_generator.py: автоматический выбор алгоритма по сложности
  образцов букв и самого глифа; прежний алгоритм сохранён для обычных форм.
  На сложных формах больше не действует автоматический запрет на жирность.
  Отчёт содержит filled_geometry_v8 и decorative_geometry.
- advanced_gui.py: диагностика нового алгоритма, тайм-аут 40 с для обычных
  и 90 с для шрифтов с более чем 2500 глифами. Отдельный процесс сохранён.
- tests/test_filled_geometry_v8.py: тесты пересекающихся контуров, направления
  жирности и изменения отверстий, ложных просветов.
- requirements.txt: добавлена Shapely.

ПРОВЕРКИ
46 модульных тестов пройдены в Linux-контейнере. На реальных TTF из архива
проверены отдельные максимальные эффекты, загрузка результата, Unicode cmap.
При counter_scale=1.30 число изменённых отверстий:
  Comforter Brush 240, Rubik Wet Paint 276, Rubik Scribble 959,
  Rampart One 449, Inter 24pt Regular 269.
При weight_scale=1.35 число глифов, обработанных новым алгоритмом:
  Comforter Brush 906, Rubik Wet Paint 772, Rubik Scribble 772,
  Rampart One 9167. Последний занял около 35 с на тестовом компьютере.
Время на Windows может отличаться. Само окно Tkinter на Windows не запускалось.

ОГРАНИЧЕНИЯ
- Не каждый белый участок декоративной буквы является замкнутым просветом.
  Например, Comforter Brush O имеет открытый просвет и остаётся неизменным
  при отдельном изменении counter_scale. Открытые просветы не реализованы.
- Тонкие контурные буквы (Rubik Scribble и др.) изменяются осторожно;
  фактическое изменение может быть намного слабее указанного коэффициента.
- У сложных глифов новые контуры состоят из коротких векторных отрезков,
  а не оригинальных кривых. Не гарантируется качество промышленной типографики.
- При слишком сложной или опасной геометрии конкретный эффект может быть
  ограничен или пропущен. Проверяйте отчёт и визуальное сравнение.
- GigaChat, базовый редактор, сессии, шрифты и прежние эффекты не заменяются.
- В архиве обновления нет TTF, окружений, секретов и пользовательских данных.

ТЕСТЫ НА ВАШЕМ ПК
   .\font-generator-venv\Scripts\python.exe -m unittest discover -s tests -v

Для визуальной проверки поставьте остальные ползунки в нейтральное положение
(width=1, slant=0, spacing=0, corner_roundness=0, serif_style=none) и изменяйте
counter_scale (0.70 / 1.30) и weight_scale (0.75 / 1.35) по отдельности.
