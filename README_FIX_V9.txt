V9 — единый GigaChat-редактор на геометрии V8

Установка: закрой оба редактора. Распакуй ZIP в D:\project_7_sem
с заменой файлов. Архив включает V8, не содержит TTF, .env, certs или сессий.
PowerShell в корне проекта:
.\font-generator-venv\Scripts\python.exe -m pip install -r requirements.txt
.\font-generator-venv\Scripts\python.exe main.py --catalog
.\font-generator-venv\Scripts\python.exe run_gui.py

Вкладки: Основные, Форма, Засечки. Всего 11 параметров. GigaChat получает
полный набор при создании, частичный патч при правке, остальные сохраняются.
В первой генерации отсутствующие новые поля и ошибочные значения получают
безопасные значения по умолчанию с пояснением. В правках неверные значения
отклоняются. Смена base_font через правку не разрешена: нужна новая сессия.
Старые сессии подставляют значения по умолчанию для новых полей.
Старые сохранённые TTF не перезаписываются.

Ручные изменения показываются через временный TTF; кнопка Сохранить TTF
создаёт постоянную версию без GigaChat. Папка с TTF открывает последнюю
сохранённую версию, не черновик. Основной GUI и CLI используют один движок
V8 в отдельном процессе (тайм-аут геометрии 90 сек). advanced_gui.py остаётся
как отдельная экспериментальная песочница. Длительные предпросмотры
выполняются последовательно; при новом запросе устаревший результат скрывается.

Проверка: output/advanced_ID/result.ttf, params.json, advanced_report.json,
quality_report.json, preview.png (создаётся при отрисовке).
.\font-generator-venv\Scripts\python.exe check_ttf.py "output\advanced_ID\result.ttf"
При наличии params.json исходник подбирается автоматически. Можно указать
--source "fonts\base\...\original.ttf" явно. Проверяются таблицы, контрольные
суммы, координаты глифов, метрики, Unicode и пробный рендер в 16/48/96 px.
Без исходника сохранность Unicode не подтверждается. Проверка не гарантирует
качество контуров: открой в FontForge, Element > Validation > Validate,
проверь в Windows и Word. Включение засечек не удаляет исходные засечки.
V8 не поддерживает произвольные открытые просветы; на сложных глифах могут
быть пропуски, скругление/засечки ограничены. Кернинг/GPOS не пересчитываются.

Тесты (без реального API):
.\font-generator-venv\Scripts\python.exe -m unittest discover -s tests -v
.\font-generator-venv\Scripts\python.exe -m unittest tests_gui -v
Тест интеграции имитирует JSON GigaChat, но реально генерирует TTF, проверяет
ручные правки, предпросмотр, историю и повторную загрузку сессии.
Реальный сетевой GigaChat и Windows проверяются на компьютере пользователя.
