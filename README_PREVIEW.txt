ЭТАП 4: PNG-ПРЕДПРОСМОТР TTF (WINDOWS)

1. В терминале VS Code перейди в папку проекта D:\project_7_sem.
2. Установи Pillow в используемый Python: python -m pip install Pillow
3. Из архива скопируй ai_main.py и папку engine в D:\project_7_sem.
   Разреши замену ai_main.py, остальные файлы engine не трогай.
4. Запусти: python ai_main.py
5. После создания result.ttf появится preview.png, и Windows откроет PNG.

Возможность рисовать кириллицу проверяется по наличию глифов в самом TTF.
При отсутствии букв мы выводим предупреждение, а не подставляем другой шрифт.

Параметры генерации и GigaChat остаются прежними. Это только новый предпросмотр.
