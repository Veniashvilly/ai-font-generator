AI FONT EDITOR — ЛОКАЛЬНОЕ ОКНО НА WINDOWS
======================================

Это ДОПОЛНЕНИЕ к твоему работающему проекту D:\project_7_sem.
Старые файлы ai/, engine/, .env, certs/, fonts/ НЕ заменяем.

ЧТО ДОБАВИТЬ
------------
1) Распакуй из архива папку gui/ и файл run_gui.py в D:\project_7_sem.
2) В VS Code открой терминал PowerShell:
     cd D:\project_7_sem
3) Если Pillow уже установлен — ничего устанавливать не нужно.
   Если нет:
     python -m pip install Pillow
4) Запусти:
     python run_gui.py

Если команда python не использует нужное окружение:
     .\.venv\Scripts\python.exe run_gui.py

КАК ПОЛЬЗОВАТЬСЯ
----------------
1. Напиши в правом поле первый запрос к GigaChat и нажми «Создать шрифт».
2. Появится картинка из реального result.ttf; текущие параметры попадут на ползунки.
3. Передвинь ползунок и ОТПУСТИ мышь. Настройки сразу сохранятся в state.json.
4. Примерно через полсекунды обновится точный предпросмотр из временного TTF.
   Это НЕ новая версия в истории, результат последнего ИИ сохранён отдельно.
5. Напиши «Сделай наклон меньше» и нажми «Применить правку ИИ».
   Перед обращением к модели сохраняется v2 (если были ручные изменения).
   Модель получает последние значения ползунков. После генерации сохранится v3.
6. Кнопка «Папка с TTF» открывает папку с последним УСПЕШНО созданным файлом.
7. Можно закрыть окно: state.json остаётся на диске. Для продолжения введи ID
   сессии в поле справа внизу и нажми «Открыть».
8. «Новая сессия» создаст новый проект после следующего запроса к ИИ.

ГДЕ СОХРАНЯЕТСЯ
---------------
sessions/<ID>/state.json              — актуальные параметры и история
output/<ID_генерации>/result.ttf      — финальный TTF
output/<ID_генерации>/preview.png     — финальный предпросмотр

Что происходит с ползунками:
- При перетаскивании меняется только цифра в интерфейсе.
- При отпускании мыши set_slider() обновляет рабочий JSON-черновик.
- Временный точный предпросмотр создаётся в временной директории Windows,
  а НЕ как постоянная новая версия шрифта.
- При отправке правки prepare_ai_request() фиксирует снимок ползунков.
- После успешного ответа ИИ создаётся новый постоянный result.ttf.

ВАЖНО
-----
- Это локальный тестовый GUI, а не фронтенд для сайта.
- Для генерации нужны твои уже работающие GigaChat, .env и исходные TTF.
- Окно не содержит и не показывает API-ключи.
- Мы не добавляли новые параметры, только width/slant/spacing.
- Временно отключённые старым движком правила кернинга GUI не восстанавливает.
- Если GigaChat выдаст ошибку, ползунки останутся сохранёнными; старый TTF цел.
