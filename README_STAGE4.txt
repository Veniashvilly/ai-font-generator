AI FONT GENERATOR — этап 4: ЯЗЫКИ И КАЧЕСТВО

Важное: НЕ удаляй существующие fonts/base, output, .env и сертификаты.
Все файлы архива просто копируются поверх соответствующих файлов в D:\project_7_sem.

Что поменялось:
1. По умолчанию (если язык не назван) выбираем универсальный RU+EN шрифт, если такой есть.
2. Запрос "только английский" фильтрует кандидатов по латинице.
3. "Русский" фильтрует по кириллице (полный русский алфавит, включая Ё).
4. "Русский и английский" требует оба алфавита.
5. Ограничения width: 0.55..1.4 вместо 0.7..1.3.
6. Перед сохранением проверяем покрытие и наличие Unicode-символов.
7. Пишем quality_report.json рядом с result.ttf и params.json.
8. preview.png показывает только нужные языки без ложного предупреждения.

ПОРЯДОК:
1. Скопировать папки ai и engine из архива с заменой перечисленных файлов.
2. В VS Code (терминал PowerShell): cd D:\project_7_sem
3. ОБЯЗАТЕЛЬНО обновить каталог, так как проверка алфавита стала строже:
   python main.py --catalog
4. Запустить: python ai_main.py
5. Пример запросов:
   "Сделай узкий шрифт только для английского текста"
   "Сделай строгий шрифт для русского текста"
   "Сделай шрифт для русского и английского, слегка наклонный"

Если GigaChat не может выбрать шрифт, сначала проверь font_catalog.json.
Если папка output уже имеет старые версии, они останутся рабочими.

ОГРАНИЧЕНИЯ:
- Это НЕ полноценная оптимизация кернинга и hinting.
- В текущем движке преобразования удаляют kern/GPOS; об этом записывается предупреждение в отчёте.
- Режим языка закрепляется при первой генерации, при редактировании сохраняется.
  Чтобы явно изменить язык или исходный шрифт, начни новую генерацию.
- Фильтр на полный алфавит может исключить шрифты с частичной поддержкой.

Дополнительно можно запустить встроенные тесты без GigaChat:
   python -m unittest discover -s tests -v
